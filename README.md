# Mutual Fund Advisor Dashboard (India)

Requirements for a web dashboard that lets an AMFI-registered mutual fund distributor manage 100+ clients: add and archive clients, record transactions (manual and CAS import), and backfill, modify and place SIPs covering up to 20 years of history.

## Documents

| Document | What it covers |
| --- | --- |
| [docs/BRD.md](docs/BRD.md) | Business Requirements: context, objectives, scope, business requirements, compliance, metrics, risks (sections 1–6) |
| [docs/PRD.md](docs/PRD.md) | Product Requirements: roles, client management, transactions, SIP management, dashboards, data model, NFRs, release plan (sections 7–14) |

## Status

Draft v1.0, 17-Nov-2026. Regulatory points (SEBI, AMFI, tax) need verification by the firm's compliance officer. Open questions are listed in PRD section 14.3.
